# Kalistenika (nazwa robocza)
Aplikacja na iPhone'a prowadząca krok po kroku do umiejętności z masą ciała (np. od podciągania negatywnego do muscle-upu), z planem dobieranym sam. Studio Apps4Brew; silnik wspólny z aplikacją Trening.

- Stan: specyfikacja (BRD), bez kodu — `docs/sztafeta.md`.
- Dokumenty: `docs/brd/` (wymagania), `docs/decyzje.md`, `docs/zalozenia.md`, `docs/monetyzacja.md`.
- Repo publiczne: bez sekretów i danych osobowych; cudze treści (research konkurencji) poza repo.
